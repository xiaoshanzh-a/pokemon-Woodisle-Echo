- 宝可梦中心与休息站：乔伊免费恢复全队，治疗台有灯光反馈；商店：柜台购买精灵球、伤药与树果；研究所：博士剧情与初始伙伴；民居：休息；树果小屋：补给；保育管理站：规则与补球；伙伴俱乐部：喂食和小游戏；娱乐城：接待、转轮与奖品兑换。各建筑电脑均可管理队伍与后备盒。
- 主角转向使用明确的纹理翻转及短暂转身动作，行走与奔跑播放方向帧。42 种伙伴增加原版双帧图标行走、步伐起伏、左右翻转、向北背面与停步姿态，沿主角轨迹跟随。伙伴侧面使用镜像，背面使用原版背图与步伐动画，并非每个物种都已具备专绘的四方向行走素材。
- 存档兼容 v0.1，新增室内名称、所属区域与出口位置；刷新或导入后仍在正确建筑内。
- 修复导航后附近野生宝可梦抢走建筑交互的问题；修复敌方伤害无视属性免疫的问题。
- `node tools/verify-interiors.cjs` 验证 13 处入口、室内服务、电脑、出口坐标、室内刷新与动画；原有主线和功能测试继续保留。

可离线运行的浏览器 2.5D 同人短篇 RPG。独立保存在 `emerald-echo/`，没有覆盖此前的火红与火箭队项目。

## 启动

双击 `start.cmd`，或在本目录运行 `node server.cjs`，打开 http://127.0.0.1:4188 。需要本机 Node.js 与支持 WebGL 的现代浏览器。不需要 npm 安装、ROM、网络账号或外部 CDN。若端口已经运行，直接打开游戏地址即可。

## 操作

- WASD / 方向键：移动；Shift：奔跑；也可以点击地面寻路。
- E / 空格：与附近的 NPC、建筑或明雷宝可梦互动。
- M：世界地图；P：队伍；B：背包；G：图鉴；J：故事手记；F：伙伴互动。
- Esc：关闭菜单；小游戏中空格回应；手机可使用地图下的触摸方向键。
- 右侧当前故事的目标按钮：前往目标所在区域，再次点击会自动寻路到目标附近。

## 可通关的主线

1. **青岚镇**：和大木博士交谈，选择妙蛙种子、小火龙或杰尼龟；皮卡丘始终保留。
2. **微光森林**：帮助林音安抚大岩蛇，获得第一枚回响碎片。
3. **潮汐渔港**：在钓鱼时机条上命中绿色区域，获得伙伴和第二枚碎片。
4. **翠野保育区**：靠近明雷宝可梦，投喂树果后投球，成功收服获得第三枚碎片。
5. **星灯街**：在本区域完成一次伙伴节奏挑战，连续命中三次，唤醒碎片。
6. **回响遗迹**：与超梦完成最终试炼，获得梦幻并进入通关后的自由探索。之后可在遗迹再次挑战并收服超梦。

剧情原创，并非火红或 Gamma Emerald 的原作剧情。区域边缘可旅行，地图菜单也可直接旅行；遗迹在第五章完成后开放。

## 系统

- Three.js 正交相机、3D 地面 / 栏杆 / 岩石 / 遗迹、像素精灵布景、深度遮挡、地面阴影、动态水面与光尘；主角方向行走帧、镜头跟随、可更换跟随伙伴。
- 42 种经典宝可梦资料与正背面图像。基础形态通过区域明雷与钓鱼出现，部分进化型通过等级进化，伊布分支、雷丘与三圣鸟通过娱乐城代币兑换，梦幻来自结局，超梦来自通关后再战。
- 简化回合制：属性克制、两种攻击、削弱后收服、换人、伤药、野外逃跑、全队经验、等级成长、部分等级进化。训练家/剧情试炼不能收服或逃跑。全队失去体力会回镇恢复。
- 六人队伍、后备盒、免费宝可梦中心、商店、树果、伙伴亲密度与节奏小游戏。
- 钓鱼：时机挑战成功即可结识随机水域伙伴；保育区：无战斗的投饵与收服。
- 娱乐城转轮仅使用游戏代币，不涉及真钱。三格相同奖励 60，任意两格相同奖励 15，每次消耗 5；伙伴节奏挑战可免费获得 25 代币。
- 自动保存：每 30 秒与关键进度后存入浏览器 localStorage。背包支持导入 / 导出 JSON；导入会校验格式并要求确认替换。不同浏览器、设备与端口的存档相互独立。
- 顶部音乐菜单可指定曲目，或设为随场景自动切换。所有场景背景音乐都优先使用用户提供的 MP3：城镇、道路、海岸、保育区、娱乐城、中心、商店、研究所、住宅、遗迹与战斗均已覆盖；短提示音仍由 Web Audio 生成。

## 验证

主线叙事围绕七年前的风暴救援与失控风铃展开：避雨棚的铜牌连接潮生与渔港，保育区解释自主选择，灯塔铃谱的空拍连接伙伴节奏，最终揭晓超梦分开核心的原因及「森屿回响」的含义。六处故事地标支持倾听/约定互动、章节后续对白和通关重访；选择写入手记及存档，首次互动增加羁绊，重复互动不刷奖励。`node tools/verify-story.cjs` 验证这些行为。剧情与角色对白集中在 `story.js`。

新增六地区石窟与隐秘花谷：室外小径连接岔路与洞口，石窟左右两路在深处会合，裂隙通往环湖花谷。皮皮救助、梦之石和泉水事件每地区各可完成一次；三段梦境奖励凯西，六段奖励皮皮。

三圣鸟支线：微光森林花谷的急冻鸟需要三段梦境；潮汐渔港花谷的闪电鸟需要三次皮皮救助；回响遗迹花谷的火焰鸟需要三处泉水记录。旅程手记显示进度；满足条件后可挑战 Lv.18 守护者，胜利获得伙伴，失败可重试，奖励不可重复领取。战斗背景按环境变化，神兽试炼有额外光效。

`node tools/verify-adventures.cjs` 检查洞窟寻路、事件、花谷存档、神兽奖励与返回室外；`node tools/verify-legendaries.cjs` 分别验证三圣鸟任务门槛和胜利奖励。

野生宝可梦刷新在可通行、可到达的位置，与建筑入口至少保持 5 个世界单位距离，并避开中央主路。门口交互优先进出建筑，普通野外遭遇会先询问是否开战；保育区仍采用投喂与收服。野外等级按区域递进，不随领队等级变化。

每个区域有一处「伙伴发现了什么？」探索点，首次调查获得树果、精灵球、旅费与羁绊奖励，领取记录随存档保存。`node tools/verify-encounters.cjs` 检查六区域安全距离、门口优先、失效目标清理，以及探索奖励不重复领取和保存恢复。

运行 `node tools/verify.cjs`。验证脚本在独立无痕浏览器里，从新存档通过界面实际完成选择伙伴、森林试炼、钓鱼、保育区收服、节奏挑战、遗迹结局及存档恢复，并检查手机宽度与浏览器错误。测试需要本机 Playwright 与 Chrome，路径写在脚本开头；不会写入用户的浏览器存档。

`tools/screenshot.cjs` 输出初始场景截图。`desktop.png`、`desktop-played.png` 与 `mobile.png` 为浏览器实际截图。

`node tools/verify-features.cjs` 补充验证商店结算、喂食、亲密度、无效存档拒绝、有效存档确认导入、导出、娱乐城转轮结算、图鉴数量与音频开关。
