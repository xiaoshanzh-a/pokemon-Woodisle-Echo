# 宝可梦 · 森屿回响

《宝可梦·森屿回响》是一款可离线运行的浏览器 2.5D 像素风单机 RPG。你将在六个主区域之间旅行，和伙伴一起调查“回响之心”的碎片，完成主线后继续调查九只神兽。

这是原创同人游戏，不是《宝可梦 火红/叶绿》或其他商业作品的完整复刻。游戏使用本地 HTML、JavaScript、Three.js、像素素材和音乐运行，不需要安装 npm、ROM、网络账号或外部 CDN。

## 运行游戏

需要 Windows、Node.js 和支持 WebGL 的现代浏览器。

最简单的方式是双击 `start.cmd`，然后打开：

```text
http://127.0.0.1:4188/
```

也可以在项目目录打开 PowerShell：

```powershell
node server.cjs
```

再访问上面的地址。不要直接双击 `index.html`，因为浏览器会限制 ES 模块和本地资源的加载。关闭游戏时，在运行 `server.cjs` 的终端按 `Ctrl+C` 即可。

## 基本操作

| 操作 | 键位 |
|---|---|
| 移动 | WASD / 方向键 |
| 奔跑 | Shift + 移动 |
| 互动、进入建筑、调查、开始野生战斗 | E 或空格 |
| 世界地图、快速旅行 | M |
| 队伍与后备盒 | P |
| 背包、补给、导入导出存档 | B |
| 宝可梦图鉴 | G |
| 故事手记、神兽调查 | J |
| 与领队伙伴互动 | F |
| 关闭窗口或菜单 | Esc |
| 镜头缩放 | 右上角“视野”按钮 |

也可以点击地图上的地面进行自动寻路，点击地点标签后主角会走到对应人物、建筑或入口附近。手机和窄屏设备可以使用地图下方的触摸方向键。

## 完整主线攻略

### 1. 青岚镇：领取伙伴

开始后先在青岚镇找到大木研究所，靠近大木博士按 E。博士会介绍“回响之心”和三枚碎片，并让你选择一只初始伙伴：妙蛙种子、小火龙或杰尼龟。皮卡丘会始终作为同行伙伴保留。

建议先去宝可梦中心恢复体力，再到商店购买精灵球、伤药和树果。

### 2. 微光森林：第一枚碎片

前往微光森林找到森林守望者林音。她会请求你帮助安抚挡路的大岩蛇。靠近林音按 E，选择开始战斗。胜利后获得第一枚回响碎片、经验和补给。

### 3. 潮汐渔港：第二枚碎片

在潮汐渔港找到老渔人或靠近钓鱼点按 E。当时机条进入绿色区域时按键。成功后会获得一只水域宝可梦，并取得第二枚回响碎片。钓鱼在主线后也可以重复进行。

### 4. 翠野保育区：第三枚碎片

找到保育员阿岚。保育区不进行普通战斗：靠近宝可梦后先投喂树果提高信任，再使用精灵球尝试捕获。成功收服一只宝可梦后获得第三枚回响碎片。这里可以遇到飞天螳螂、袋兽、肯泰罗、吉利蛋、尼多兰、尼多朗和迷你龙等宝可梦。

### 5. 星灯街：伙伴节奏挑战

前往星灯街，在伙伴俱乐部或娱乐城附近按 F 与领队互动，选择“心跳节拍小游戏”。连续三次在绿色区域按键即可完成挑战。失败可以重试，不消耗精灵球。完成后，三枚碎片共鸣，回响遗迹开放。

### 6. 回响遗迹：完成主线

前往回响遗迹，找到回响守护者并按 E。完成最终试炼后，主线进入终章，梦幻会加入队伍或后备盒。

剧情战斗中的超梦不能直接捕获。主线通关后回到遗迹，再次与它互动即可挑战并收服超梦。

## 主线通关后：神兽调查

神兽出现必须满足以下条件：

1. 完成森林、渔港、保育区和星灯街的四个主线阶段。
2. 在回响遗迹完成最终试炼。
3. 回到青岚镇的大木研究所。
4. 再次和大木博士交谈。
5. 选择“接下生态调查”。

大木博士首次开启调查时会赠送 **3 枚大师球**。之后每轮记录三个指定区域的生态样点，回研究所提交，再获得 **3 枚大师球**，可以无限重复。

打开 M 地图，在地图下方选择“开阔野外通路”。选择地图后，主角会自动走向入口；靠近入口后还需要按 E 才会进入。

| 神兽区域 | 进入位置 | 神兽 |
|---|---|---|
| 风息原野 | 青岚镇、微光森林 | 哲尔尼亚斯、苍响、基拉祈 |
| 云脊山径 | 微光森林、回响遗迹 | 烈空坐、莱希拉姆、露奈雅拉 |
| 星汐湿地 | 潮汐渔港、星灯街 | 水君、洛奇亚、克雷色利亚 |

神兽会出现在支路的开阔空地。靠近后按 E，阅读线索并选择开始战斗。神兽战败、逃离或离开后可以重新挑战，只有成功收服才会从地图上消失。普通精灵球需要先削弱神兽体力；大师球可以直接保证捕获。

## 捕获和战斗

普通主区域中的宝可梦会以明雷形式出现。靠近后按 E，可以选择开始战斗或绕开。战斗中可以使用招式、精灵球、大师球、伤药、更换伙伴，或逃离普通野生战斗。

剧情试炼和训练家战斗不能捕获对手的宝可梦。训练家切磋是自愿的，部分 NPC 会根据身份使用不同伙伴，例如山道维护员使用大岩蛇，水手使用拉普拉斯，遗迹训练家使用波士可多拉。

战斗胜利会给予经验和旅费。属性克制包括水克火、火克草、电克水、草克水和岩石、格斗克一般和岩石、妖精克龙等。

## 队伍、经验和进化

队伍最多六只宝可梦，超过六只会进入后备盒。按 P 可以更换领队、管理后备盒、查看 HP、羁绊、等级和经验，以及选择分支进化。

经验条显示在右侧队伍面板、队伍详情和战斗界面。普通等级进化在战斗胜利结算时自动触发。当前图鉴共 113 种，包含多个完整进化链：

- 绿毛虫 → 铁甲蛹 → 巴大蝶
- 独角虫 → 铁壳蛹 → 大针蜂
- 波波 → 比比鸟 → 大比鸟
- 凯西 → 勇基拉 → 胡地
- 鬼斯 → 鬼斯通 → 耿鬼
- 迷你龙 → 哈克龙 → 快龙
- 拉鲁拉丝 → 奇鲁莉安 → 沙奈朵 / 艾路雷朵
- 可可多拉 → 可多拉 → 波士可多拉
- 烛光灵 → 灯火幽灵 → 水晶灯火灵

原作中需要通信、进化石或特殊条件的形态，在本作采用单机适配规则。达到队伍界面显示的等级后，可以点击目标形态并确认。伊布、奇鲁莉安和飞天螳螂等分支进化会保留选择。

## 建筑和设施

- 宝可梦中心：免费恢复全队 HP。
- 商店：购买精灵球、伤药和树果。
- 大木研究所：选择初始伙伴、推进主线、领取大师球和提交生态调查。
- 保育区管理站：了解保育区规则并补充精灵球。
- 树果小屋：补满树果篮。
- 伙伴俱乐部：喂树果、增加羁绊、进行节奏小游戏。
- 娱乐城：转轮和奖品兑换，使用游戏代币，不涉及真钱。
- 居民房和休息站：恢复状态并触发地方对话。

进入建筑后，人物不能穿过墙、柜台或大型设备。走到室内下方出口附近按 E，可以返回进入前的建筑门口。

## 地图与支线探索

按 M 可以查看六个主区域、三张神兽支路、建筑入口和沿途路线。按 J 可以查看主线、神兽调查、生态样点、地方人物故事、沿途观察点和已收服神兽。

每个主区域有一处“伙伴发现了什么？”探索点。首次调查通常会获得树果、精灵球、旅费和羁绊奖励，同一存档不会重复领取。

## 存档和新游戏

点击右上角“保存旅程”可以打开九个独立存档栏：

- 旧版单一存档会自动迁移到 1 号栏。
- 保存到其他栏位会复制当前旅程。
- 读取存档会切换当前自动保存目标。
- 覆盖已有栏位需要二次确认。
- “新游戏”只允许选择空白栏，不会清空已有旅程。
- 背包支持导出和导入 JSON 存档。

存档保存在当前浏览器和当前地址的 localStorage 中。换浏览器、换设备或换端口时，存档不会自动同步，建议重要进度使用背包的“导出存档”。

## 音乐

顶部声音按钮可以开启或关闭音乐，音乐菜单可以选择“随场景自动切换”或指定曲目。自动模式会根据城镇、森林、海岸、保育区、娱乐城、商店、研究所、住宅、遗迹和战斗切换音乐。场景切换、战斗结束、页面重新获得焦点后都会尝试恢复播放；如果 MP3 加载失败，会使用备用合成旋律继续播放。

## 常见问题

### 大木博士任务后为什么看不到神兽？

必须先完成回响遗迹最终试炼，再回研究所选择“接下生态调查”。初次对话只是主线任务，不会开启神兽。

### 我已经进入神兽区域，为什么没有神兽？

确认已经接下生态调查，进入的是三张“开阔野外通路”而不是普通主区域，并且已经靠近入口按 E。已经收服的神兽不会再次显示。

### 游戏没有声音怎么办？

先点击右上角声音按钮启用音频。浏览器通常要求用户先点击一次页面才能播放声音。换场后如果暂时无声，再点击页面或声音按钮即可恢复。

### 如何获得更多大师球？

完成主线后找大木博士接生态调查。首次获得 3 枚；每轮完成三个指定生态样点并提交，再获得 3 枚。

## 项目结构

```text
index.html          游戏页面
game.js             游戏流程、战斗、任务、存档和 UI
world.js            地图渲染、移动、碰撞和建筑
data.js             区域、宝可梦、任务和招式数据
legend-*.js         神兽、调查和神兽特效
evolution.js        进化链和经验规则
assets/             宝可梦、地图、建筑、植物和音乐素材
vendor/             本地 Three.js 依赖
server.cjs          本地静态服务器
start.cmd           Windows 启动脚本
tools/              测试和素材处理脚本
```

## 项目范围

本作是六区域原创短篇版本，未实现商业正作的全部地图、道馆体系、全部招式和特性、双打、联网交换、繁育、Mega 进化以及完整天气系统。游戏重点是探索、伙伴关系、地方故事、神兽调查和可重复游玩。
